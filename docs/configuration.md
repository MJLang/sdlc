# Configuration reference

Generated by `npm run config:docs` from `lib/config-schema.mjs`, the single
authority for the `.agents/sdlc.json` key set. Do not hand-edit this file;
change the schema and regenerate.

`.agents/sdlc.json` is the shared, committed project configuration.
`.agents/sdlc.local.json` is an optional, machine-scoped, Git-ignored overlay
of it. A reader can write a valid `.agents/sdlc.json` from this document
alone, without reading `lib/`.

## Overlay rules

`.agents/sdlc.local.json` may declare only these top-level keys: `$schema`, `version`, `local`, `models`.
Every other top-level key is refused *by name* - the boundary is derived from
each key's `localOverridable` field in `lib/config-schema.mjs`, not a
hand-maintained list, so it cannot silently drift out of step with the schema.
`local` and `models` merge deep, leaf-wise, between the shared and local
files; arrays and scalars are whole-value replacements, with the local file's
value winning.

## Provenance

Every effective setting reports the file that produced it. `sdlc config`,
`sdlc doctor --json`, and every `sdlc guard <stage> --json` carry a
`sources` map keyed by dotted field path (e.g. `local.reviewEditor`) whose
value is the repository-relative path of the file that set it, or the literal
string `default` when no file did.

## Editor validation

Two JSON Schema (draft 2020-12) documents ship alongside the template:
`template/sdlc.schema.json` describes the full `.agents/sdlc.json` shape,
and `template/sdlc.local.schema.json` describes the restricted
`.agents/sdlc.local.json` overlay shape. Point an editor at one by setting
the `$schema` key in the file it should validate:

```json
{ "$schema": "./sdlc.schema.json", "version": 1 }
```

`$schema` configures editor tooling only; it has no effect on pipeline
behavior, and is excluded from `sdlc config`'s effective-settings listing.

## `models` is reserved policy

The `models` block validates against this schema, resolves per host, and is
reported by `sdlc config`, but **nothing in the pipeline consumes it yet**.
Declaring it today changes no subagent's model or reasoning effort. It ships
now so that adopting a role-to-tier-to-model policy later needs no second
migration and no format change.

## Keys

| Key | Type | Required | Default | Local override | Description | Example |
|---|---|---|---|---|---|---|
| `$schema` | string | No | `null` | Yes | Path to the JSON Schema file, for editor validation; has no effect on pipeline behavior. | `./sdlc.schema.json` |
| `version` | integer | Yes | required | Yes | Schema version for `.agents/sdlc.json`; only `1` is recognized today. | `1` |
| `targets` | object[] | Yes | required | No | Ordered list of named work lanes; declaration order sets precedence when target paths overlap. | `[{"name":"app","paths":["src/**","test/**"],"gates":["npm run test:app"],"reviewers":["backend-code-reviewer"]}]` |
| `targets[].name` | string | Yes | required | No | Lane identifier; must match /^[a-z][a-z0-9-]*$/ and be unique among targets. | `app` |
| `targets[].paths` | string[] | No | `[]` | No | Glob patterns whose changed files belong to this target. | `["src/**","test/**"]` |
| `targets[].gates` | string[] | No | `[]` | No | Quality-gate commands run in addition to the top-level gates when this target is selected. | `["npm run test:app"]` |
| `targets[].reviewers` | string[] | No | _inherits the top-level reviewers_ | No | Reviewer profiles for this target; inherits the top-level reviewers when omitted. | `["backend-code-reviewer"]` |
| `gates` | string[] | No | `[]` | No | Quality-gate commands run for every target. | `["npm test"]` |
| `reviewers` | string[] | No | `[]` | No | Default reviewer profiles for targets that do not declare their own. | `["backend-code-reviewer"]` |
| `productDocs` | string | No | `thoughts/docs/` | No | Repository-relative directory of durable product documentation. | `thoughts/docs/` |
| `frontendConstraints` | string | No | `none` | No | Prose constraints frontend reviewers and implementers must honor. | `none` |
| `beads.mode` | enum (embedded, server) | No | `embedded` | No | Beads coordination backend: an embedded local store or a shared server. | `embedded` |
| `beads.mergeSlot` | enum (off, on) | No | `off` | No | Whether the single-writer merge slot is enforced before landing. | `off` |
| `local.reviewEditor` | string | No | `null` | Yes | Command template that opens a worktree in the developer's editor; machine-scoped. | `code {worktree}` |
| `local.preview.command` | string | No | `null` | Yes | Command template that starts a local preview server; machine-scoped. | `npm run dev -- --port {port}` |
| `local.preview.url` | string | No | `null` | Yes | URL template for the local preview server; machine-scoped. | `http://localhost:{port}` |
| `models.defaults.tier` | enum (frontier, balanced, cheap) | No | `balanced` | Yes | Fallback model tier for roles that do not declare their own. | `balanced` |
| `models.defaults.effort` | enum (low, medium, high) | No | `medium` | Yes | Fallback reasoning effort for roles that do not declare their own. | `medium` |
| `models.roles` | object | No | `{}` | Yes | Per-role tier/effort overrides; role names are open-ended. | `{"plan-reviewer":{"tier":"frontier","effort":"high"}}` |
| `models.roles.<role>.tier` | enum (frontier, balanced, cheap) | No | _inherits models.defaults.tier_ | Yes | Model tier for this role; falls back to models.defaults.tier. | `frontier` |
| `models.roles.<role>.effort` | enum (low, medium, high) | No | _inherits models.defaults.effort_ | Yes | Reasoning effort for this role; falls back to models.defaults.effort. | `high` |
| `models.tiers` | object | No | `{}` | Yes | Per-host model identifiers for each tier. | `{"claude":{"frontier":"inherit","balanced":"sonnet","cheap":"haiku"}}` |
| `models.tiers.<host>.<tier>` | string | No | none | Yes | Concrete model identifier a host resolves this tier to. | `sonnet` |

## Legacy migration

Projects created before 0.6.0 declared these settings as Markdown under
`## Project Configuration` in `thoughts/AGENTS.md`. That section is gone;
`sdlc setup` refuses to run while it remains. Move each value by hand to the
dotted key that replaced it, then delete the section:

| Old label (`## Project Configuration`) | New key |
|---|---|
| **Targets** | `targets` |
| **Target paths** | `targets[].paths` |
| **Target gates** | `targets[].gates` |
| **Quality gates** | `gates` |
| **Reviewers** | `reviewers` |
| **Product docs** | `productDocs` |
| **Frontend constraints** | `frontendConstraints` |
| **Beads mode** | `beads.mode` |
| **Beads merge slot** | `beads.mergeSlot` |
| **Review editor** | `local.reviewEditor` |
| **Local preview** | `local.preview.command` |
| **Preview URL** | `local.preview.url` |
